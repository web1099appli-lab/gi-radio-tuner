# GI-Radio Tuner

**Le lecteur et enregistreur de radios Internet gratuit.** Application Windows 10 / 11 (64 bits).

GI-Radio Tuner écoute les radios du monde entier, affiche le titre en cours et enregistre vos émissions
morceau par morceau, sans perte de qualité. Il ouvre directement les tuners `.db3` d'Internet Digital Radio Tuner.

## Télécharger

👉 **[Dernière version](https://github.com/web1099appli-lab/gi-radio-tuner/releases/latest)** :
`GI-RadioTuner-Setup-x.y.z.exe` (installeur) ou `GI-RadioTuner-Portable-x.y.z.exe` (sans installation).

Le logiciel n'est pas signé par un certificat payant : si Windows affiche « Windows a protégé votre
ordinateur », cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.

## Fonctions

- Lecture **MP3, AAC, OGG, Opus, FLAC, HLS** et playlists `.pls` / `.m3u` / `.asx`
- **Titre en cours**, format, débit, fréquence, et **historique** des titres diffusés
- **Radios en ligne** : recherche par nom, style ou pays dans l'annuaire libre radio-browser.info, ajout en un clic avec le logo
- **Tuners `.db3`** compatibles avec Internet Digital Radio Tuner : nouveau, ouvrir, importer (`.db3`, `.m3u`, `.pls`), exporter en `.m3u`
- Classement par **styles, pays et réseaux**, vue mosaïque ou liste, **favoris**, radio au hasard
- **Enregistrement direct** sans réencodage, **découpé par titre** (« Artiste - Titre »)
- **Spectromètre**, spectre circulaire ou oscilloscope
- **Minuterie d'arrêt**, reconnexion automatique, choix de la **sortie audio**
- **Mini-lecteur**, zone de notification, touches multimédia, **5 thèmes** (dont un clair)

## Raccourcis clavier

| Touches | Action |
|---|---|
| Espace | Lecture / pause |
| Ctrl+F | Rechercher |
| Ctrl+N | Nouvelle radio |
| Ctrl+R | Enregistrer |
| ↑ / ↓ | Volume |
